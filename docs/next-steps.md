# Mapa produktu i odbiór — Porcelana

## Zrealizowany zakres

1. Start: Oddech, Skupienie, Wyciszenie, Sen, Energia.
2. Ścieżki i biblioteka: wszystkie protokoły, filtry celu/czasu, wyszukiwanie oraz pięć programów.
3. Przygotowanie: przebieg, czas, głośność/tło, test kanałów, opcjonalna minuta oddechu i rozwijane szczegóły.
4. Odtwarzacz: wspólny zegar, pauza/wznowienie, zakończenie, głośność, pełny ekran, tryb bez animacji, ograniczony ruch i przygaszenie snu.
5. Zakończenie i historia: rzeczywisty czas aktywności, opcjonalna ocena, lokalny zapis oraz eksport danych.
6. Eksport audio: WAV z postępem i anulowaniem; dodatkowo SVG i JSON.
7. Materiały: osobna instrukcja i whitepaper PL/EN, druk, źródła oraz strona promocyjna pięciu ścieżek.

## Odbiór przed publikacją

Podgląd lokalny: `http://127.0.0.1:8770/`. Testy i znane granice w `premium-qa.md`. Zmiany przygotowane są razem na gałęzi `codex/porcelain-design`. Produkcja nie jest publikowana automatycznie z tej gałęzi.

Do odbioru użytkownika: estetyka, czytelność treści i odczucie prowadzenia sesji. Przed publikacją zalecany jest odsłuch stereo na docelowych słuchawkach oraz test fizycznego telefonu (Safari iOS / Chrome Android). Emulacja geometrii nie zastępuje testu polityk audio urządzenia.

Po akceptacji opublikować cały zestaw plików, zachowując adresy GitHub Pages. Powrót do poprzedniego wyglądu jest możliwy przez odwrócenie commitu przebudowy; preferencje i historia starej wersji nie zostały usunięte. Nowe dane można pobrać jako JSON przed powrotem.
